Aplicação web desenvolvida em Python com Flask para gerenciamento completo (CRUD) de produtos e categorias. O projeto implementa persistência em banco de dados relacional SQLite (relacionamento 1:N), validação de dados no back-end, upload seguro de imagens e limpeza automática de arquivos obsoletos no disco.

## Tecnologias Utilizadas
* **Python 3**
* **Flask** (Estrutura modular com Blueprints e Application Factory)
* **Flask-SQLAlchemy** (ORM e modelagem relacional SQLite)
* **HTML5 / Jinja2 / Bootstrap 5** (Interface responsiva)

## Como Rodar 
pip install flask flask_sqlalchemy
python run.py
